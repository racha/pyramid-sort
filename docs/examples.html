Examples

The jagged block, then the wedge.

Each line is drawn as wide as it is long. Ascending puts the short line on top. A blank line is a group boundary, and both sides keep it.

Imports

External packages, then local and alias paths. Length sort happens inside each group.

Attributes

Multiline tags only. A spread such as {...props} stays fixed. Named attributes sort on either side and do not cross it.

Types

The blank line stays. Each side sorts on its own.

Objects

CSS

Declarations inside the rule. The selector stays the selector.
