The project

Source and issues live on GitHub. Releases publish the npm package pyramid-sort and the VS Code extension INVEON-Development.pyramid-sort. The license is MIT.

Config for a repo is .pyramidsort. Files to skip are .pyramidsortignore. Both are documented in the repository README, which is the reference when this page and the tool disagree.
