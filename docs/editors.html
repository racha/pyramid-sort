Editors

Wherever the file is open.

The extension is a VS Code extension. Cursor loads it. Antigravity can run the same CLI. .pyramidsort is the shared config, so the editor and the terminal do not drift apart.

VS Code

On save.

Search the Marketplace for Pyramid Sort, publisher INVEON-Development.

code --install-extension INVEON-Development.pyramid-sort

Imports and attributes sort on save. Types, objects, and CSS wait until you enable them. The Problems tab reports order when diagnostics for that category are on. The lightbulb runs the matching sort.

Useful commands: Pyramid Sort, category sorts, Force Sort, Save Without Sorting, Generate Config File, Scan All Files, Sort All Files.

Cursor

Extension, then the agent.

Install the same extension. Cursor reads VS Code extensions, so on-save and the Problems tab behave the same way.

cursor --install-extension INVEON-Development.pyramid-sort

For edits the agent makes through tools, on-save is not enough. Pyramid Sort: Setup AI Hook & Cursor Rules writes .cursor/rules/pyramid-sort.mdc so the agent calls the CLI. A stop hook can do it without being asked. That setup is on the AI workflow page.

Generate .pyramidsort once. The rule should pass every edited path in one call and should not pass --imports-only unless you mean to override that file.

Antigravity

Same CLI. Same file.

There is no separate Antigravity plugin. The Antigravity IDE is in the VS Code family, so install the VSIX from the Extensions view (Install from VSIX) or from the Marketplace if it is listed. Inside VS Code, the Google Antigravity extension is the agent; Pyramid Sort is still the formatter.

npx pyramid-sort src/App.tsx src/pages/home.tsx

Tell the agent, or an agy task, to run that after it edits matching files. Categories come from the nearest .pyramidsort. .pyramidsortignore uses gitignore syntax when you want a folder left alone.

A directory is not a file list. npx pyramid-sort . does nothing useful until you add --scan or --sort-all. --sort-all rewrites the tree using the same on-save toggles. --all-categories ignores those toggles and sorts everything.
